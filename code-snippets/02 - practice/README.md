# 🛠️ C++ Practice Projects

This folder contains small C++ projects designed to help you practice the concepts introduced in the `basics/` folder.

Unlike the examples in `basics/`, these projects combine multiple concepts together to create working programs.

## Projects

| project                   | concepts practiced                           |
| ------------------------- | -------------------------------------------- |
| `01_calculator`           | variables, input/output, arithmetic, switch  |
| `02_number_guessing_game` | variables, loops, conditions, random numbers |
| `03_pattern_generator`    | input/output, loops, nested loops            |

More projects can be added.

## How to use this folder?

For each project:

1. Read the project description.
2. Run the program.
3. Try to understand how it works.
4. Experiment with the code.
5. Try adding your own features.

## Important

These projects aren't meant to be copied line-by-line.

If you don't understand something, go back to the relevant example in `basics/` and review the concept before continuing. The goal is to gradually become comfortable combining different C++ concepts into your own programs.

## What's next?

Once you're comfortable with the projects here, try creating your own small programs without following an example.

You can always come back to the `basics/` folder whenever you need a refresher.
