# C++ Basics

A collection of beginner-friendly c++ examples covering the fundamental concepts of the language.

These examples are meant to be **read, run, and experimented with**. The explanations at the bottom of each file give some context without explaining every single line for you.

## Topics

| file                   | topic                              |
| ---------------------- | ---------------------------------- |
| `01_hello_world.cpp`   | basic program structure and output |
| `02_variables.cpp`     | variables and basic data types     |
| `03_input_output.cpp`  | user input and output              |
| `04_arithmetic.cpp`    | arithmetic operators               |
| `05_if_else.cpp`       | conditional statements             |
| `06_switch.cpp`        | switch statements                  |
| `07_for_loop.cpp`      | for loops                          |
| `08_while_loop.cpp`    | while loops                        |
| `09_do_while_loop.cpp` | do-while loops                     |
| `10_nested_loops.cpp`  | nested loops                       |
| `11_functions.cpp`     | functions and parameters           |
| `12_arrays.cpp`        | arrays and indexing                |
| `13_strings.cpp`       | strings and string operations      |
| `14_references.cpp`    | references                         |
| `15_pointers.cpp`      | pointers and memory addresses      |
| `16_structs.cpp`       | structures and custom data types   |


The files are arranged roughly from simpler concepts to more advanced ones, so it's recommended to go through them in order.

For each example:

1. Read the code first.
2. Try to understand what you think it does.
3. Run the program.
4. Experiment by changing values or parts of the code.
5. Read the explanation at the bottom.
6. Try writing a similar example yourself.

Don't be afraid to break the code. Experimenting is part of learning.

## Remember

You don't need to memorize every piece of syntax immediately.

The goal of this folder is to understand the **basic building blocks of C++** and how they work together.

Once you're comfortable with these concepts, move on to the `practice/` folder and start combining them into actual programs.
